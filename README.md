# Дз 14

В этой работе выполнены задания на использование циклов, проверку чисел и работу с условиями.

---

# Что делает программа

1. Выводит числа от `20` до `30` с шагом `0.5`.

2. Рассчитывает стоимость `10`, `20`, `30` ... `100` долларов в гривнах по курсу `27 грн`.

3. Запрашивает целое число `N` и выводит все числа от `1` до `100`, квадрат которых не превышает `N`.

4. Проверяет, является ли введённое число простым.

5. Проверяет, можно ли получить введённое число возведением числа `3` в степень.

6. Использует тернарный оператор для вывода результата проверки числа.
