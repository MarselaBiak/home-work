# Дз 5

В этой работе выполнены эксперименты с типами данных `Number`, `BigInt` и `String`.

---

# Что делает программа

1. Выводит разные виды чисел:
   - положительное число;
   - отрицательное число;
   - число с плавающей точкой;
   - большое число;
   - маленькое число;
   - число с разделителем `_`.

2. Проверяет специальные числовые значения:
   - `Infinity`;
   - `-Infinity`;
   - `NaN`.

3. Показывает результат вычисления `0.1 + 0.2`.

4. Проверяет значения после `Number.MAX_SAFE_INTEGER`.

5. Выполняет арифметические операции с `NaN`.

6. Создаёт значения `BigInt` двумя способами:
   - с помощью `n`;
   - с помощью `BigInt()`.

7. Сравнивает `BigInt` и `Number`.

8. Создаёт строки с помощью:
   - одинарных кавычек;
   - двойных кавычек;
   - обратных кавычек.

9. Использует экранирование кавычек и шаблонные строки.

10. Выводит имя, возраст, город и возраст в месяцах.

11. Определяет:
    - длину строки;
    - первый символ;
    - пятый символ;
    - последний символ.

12. Проверяет неизменяемость строк в JavaScript.

13. Переводит цену из копеек в гривны и копейки.
