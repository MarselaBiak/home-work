# Дз 22

В этой работе реализованы собственные аналоги методов `bind()`, `call()` и `apply()` для работы с контекстом `this` в JavaScript.

---

# Что делает программа

1. Создаёт объект `user` с данными пользователя и методом `showName()`.

2. Реализует собственную функцию `bind`, которая привязывает переданную функцию к указанному объекту.

3. `bind` не вызывает функцию сразу, а возвращает новую функцию с сохранённым контекстом `this`.

4. Передаёт аргументы в `bind` с помощью rest-параметра `...args`.

5. Реализует собственную функцию `call`, которая сразу вызывает переданную функцию с явно указанным контекстом `this`.

6. Передаёт аргументы в `call` отдельно через запятую.

7. Реализует собственную функцию `apply`, которая сразу вызывает функцию с указанным контекстом `this`.

8. Передаёт аргументы в `apply` в виде массива.

9. Для временного вызова функции в нужном контексте функция добавляется в объект как временное свойство `temp`.

10. После выполнения временное свойство удаляется с помощью `delete`.

11. Результаты работы `bind`, `call` и `apply` выводятся в консоль.
