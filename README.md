# Дз 11

В этой работе изучены логические операторы и проверка нескольких условий в JavaScript.

---

# Что делает программа

1. Создаёт данные для проверки скидки:
   - наличие промокода;
   - сумма корзины;
   - Black Friday.

2. Проверяет, можно ли применить скидку.

3. Использует операторы:
   - `&&`;
   - `||`;
   - `!`.

4. Выводит:
   - `Скидка применена`;
   - `Скидка не применена`.

5. Создаёт данные для формы входа:
   - email;
   - пароль;
   - подтверждение email.

6. Проверяет, что email и пароль не пустые.

7. Создаёт переменную `canLogin`.

8. Выводит:
   - `Логин успешный`;
   - `Проверьте данные`.
