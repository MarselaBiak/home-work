# Дз 19

В этой работе вручную реализованы аналоги методов массивов `shift()` и `reverse()` без использования встроенных методов массивов.

---

# **Что делает программа**

1. Реализует функцию `shiftFunc`, которая работает аналогично методу `shift()`.

2. Сохраняет первый элемент массива перед его удалением.

3. С помощью цикла `for` сдвигает все остальные элементы массива на одну позицию влево.

4. Уменьшает длину массива через `arr.length--`, тем самым удаляя последний лишний элемент.

5. Возвращает удалённый первый элемент.

6. Если массив пустой, возвращает `undefined`.

7. Реализует функцию `reverseFunc`, которая работает аналогично методу `reverse()`.

8. Проходит только до середины массива.

9. Меняет элементы с начала и конца массива местами с помощью временной переменной.

10. Возвращает перевёрнутый массив.

11. Обе функции изменяют исходный массив.

12. Результаты работы функций проверяются через `console.log()`.
