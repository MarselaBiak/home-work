# Дз 13

В этой работе реализованы два задания: валидатор возраста и конвертер температуры. Используются условные конструкции, тернарный оператор, `switch`, объект-мапа и проверки введённых данных.

---

# Что делает программа

1. Запрашивает возраст пользователя через `prompt`.

2. Преобразует введённый возраст в число через `Number()`.

3. Проверяет корректность возраста:
   - пользователь не нажал `Cancel`;
   - строка не пустая;
   - строка не состоит только из пробелов;
   - значение является конечным числом;
   - возраст является целым числом.

4. Определяет возрастную категорию:
   - дошкольник;
   - несовершеннолетний;
   - взрослый;
   - пенсионер;
   - проверяет отрицательный и слишком большой возраст.

5. С помощью тернарного оператора определяет возможность управления автомобилем.

6. С помощью вложенного тернарного оператора определяет стоимость билета:
   - `0 грн`;
   - `50 грн`;
   - `100 грн`.

7. Запрашивает температуру в градусах Цельсия и шкалу для конвертации:
   - `F` — Фаренгейт;
   - `K` — Кельвин;
   - `R` — Ранкин.

8. Проверяет корректность введённой температуры и значение абсолютного нуля.

9. Приводит название шкалы к нижнему регистру через `toLowerCase()`.

10. Использует объект `scaleNames` для хранения названий температурных шкал.

11. Проверяет наличие шкалы через `Object.hasOwn()`.

12. Конвертирует температуру в выбранную шкалу.

13. Округляет результат до двух знаков после запятой.

14. С помощью тернарного оператора определяет состояние температуры:
   - мороз;
   - холодно;
   - прохолодно;
   - комфортно;
   - спека.

15. Выводит итоговый результат в консоль.
