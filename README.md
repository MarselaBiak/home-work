# Дз 16

В этой работе реализована функция для генерации случайного ключа заданной длины из указанного набора символов.

---

# Что делает программа

1. Хранит набор символов, из которых будет создаваться ключ.

2. Принимает длину будущего ключа через параметр `length`.

3. С помощью цикла `for` повторяет генерацию нужное количество раз.

4. На каждом шаге выбирает случайный индекс из строки `characters`.

5. Добавляет выбранный символ в итоговую строку.

6. Возвращает готовый случайный ключ через `return`.

7. Выводит результат работы функции в консоль.
