# Дз 6

В этой работе создан персонаж для ролевой игры с характеристиками, инвентарём, способностями и местоположением.

---

# Что делает программа

1. Создаёт объект `hero` с основной информацией о персонаже:
   - имя;
   - класс;
   - уровень;
   - статус жизни.

2. Создаёт объект `stats` с характеристиками персонажа:
   - здоровье;
   - мана;
   - сила;
   - ловкость;
   - интеллект.

3. Добавляет объект `stats` внутрь объекта `hero`.

4. Выводит в консоль:
   - весь объект героя;
   - имя;
   - класс;
   - уровень;
   - статус жизни;
   - характеристики;
   - силу;
   - интеллект, умноженный на 2.

5. Добавляет герою массив `inventory` с предметами.

6. Выводит:
   - весь инвентарь;
   - первый предмет;
   - последний предмет;
   - количество предметов.

7. Создаёт объект `enemy` со свойствами:
   - свойство с пробелами;
   - свойство с дефисом;
   - вычисляемое свойство.

8. Получает значения сложных свойств с помощью квадратных скобок.

9. Добавляет герою объект `abilities` с функциями:
   - атака;
   - восстановление здоровья;
   - повышение уровня.

10. Использует обычную и стрелочные функции.

11. Добавляет герою объект `location`, который содержит:
   - регион;
   - город;
   - координаты `x`, `y` и `z`.

12. Создаёт второго персонажа `villain` с характеристиками, инвентарём, способностями и местоположением.

13. Сравнивает здоровье героя и злодея.

14. Выводит имя персонажа, у которого больше здоровья.

15. Выводит участников дуэли и содержимое их инвентарей.
