# Дз 24

В этой работе реализовано появление и скрытие блока `div` в зависимости от фокуса на текстовом поле `input`.

---

# Что делает программа

1. На странице находится текстовое поле `input`.

2. Также на странице находится блок `div`, который изначально скрыт.

3. JavaScript находит элементы `input` и `div` с помощью `querySelector()`.

4. Для `input` добавляется обработчик события `focus`.

5. Когда пользователь нажимает на текстовое поле и оно получает фокус, блок `div` появляется.

6. Для появления блока используется изменение свойства `style.display`.

7. Для `input` также добавляется обработчик события `blur`.

8. Когда текстовое поле теряет фокус, блок `div` снова скрывается.
