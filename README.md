# Дз 18

В этой работе реализована функция `removeElement`, которая удаляет указанный элемент из массива.

---

# Что делает программа

1. Принимает массив и элемент, который нужно удалить.

2. С помощью `indexOf()` ищет индекс нужного элемента.

3. Проверяет, существует ли элемент в массиве.

4. Если элемент найден, удаляет его с помощью `splice()`.

5. Удаляет только один найденный элемент.

6. Возвращает изменённый массив через `return`.

7. Выводит результаты работы функции в консоль.
