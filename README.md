# ДЗ 29. Todo List на архітектурі MVC

У цій роботі реалізовано застосунок **Todo List** для керування списком задач із використанням архітектурного патерну **MVC (Model – View – Controller)**. Застосунок дозволяє створювати, редагувати, видаляти та відзначати виконані задачі, виконувати пошук і фільтрацію. Дані зберігаються в `localStorage` та відновлюються після перезавантаження сторінки.

## Що робить програма

- Відображає список задач із назвою, описом, датами створення та оновлення.
- Дозволяє створювати нові задачі.
- Перевіряє, щоб назва задачі не була порожньою.
- Автоматично генерує унікальний `id` для кожної задачі.
- Дозволяє позначати задачі як виконані за допомогою `checkbox`.
- Візуально виділяє виконані задачі.
- Дозволяє редагувати назву та опис задачі через модальне вікно.
- Реалізує видалення задачі з підтвердженням.
- Автоматично оновлює дату при зміні задачі.
- Виконує пошук задач за назвою без урахування регістру.
- Підтримує фільтрацію задач: `All`, `Active`, `Completed`.
- Дозволяє одночасно використовувати пошук і фільтрацію.
- Зберігає задачі в `localStorage` у форматі JSON.
- Відновлює дані після перезавантаження сторінки.
- Зберігає пошуковий запит і незавершене введення нової задачі.
- Зберігає стан модальних вікон і вибраного фільтра в URL.
- Відновлює відповідне модальне вікно після перезавантаження сторінки.
- Відображає повідомлення, якщо задач немає.

## Архітектура MVC

Застосунок розділений на три основні компоненти:

- **Model** — відповідає за роботу з даними, створення, редагування, видалення, пошук і фільтрацію задач, а також збереження у `localStorage`.
- **View** — відповідає за створення та оновлення HTML-елементів, відображення задач, заповнення модальних вікон і візуальне виділення активного фільтра.
- **Controller** — обробляє події користувача, взаємодіє з Model і View, керує параметрами URL та відновленням стану інтерфейсу.

Для організації коду використовуються ES-модулі з `import` та `export default`.

## Формат збереження

Кожна задача представлена об'єктом:

```js
{
    id: 1,
    title: "Изучить MVC",
    description: "Разобраться с Model, View и Controller",
    completed: true,
    createdAt: "2026-10-19",
    updatedAt: "2026-10-20"
}
```

Масив задач зберігається в `localStorage` під ключем `todos`.

Для перетворення даних використовується `JSON.stringify()`, а для відновлення — `JSON.parse()`.

Якщо збережені задачі відсутні, застосунок використовує початкові дані з `todos.js`.

## Робота з URL

Для збереження стану інтерфейсу використовуються параметри URL.

Приклади:

```text
?filter=active
?filter=completed
?action=edit&todoId=5
?action=delete&todoId=5
```

Після відкриття посилання або перезавантаження сторінки відповідний фільтр чи модальне вікно відновлюється автоматично.

При закритті модального вікна параметри `action` і `todoId` видаляються з URL.
