# ДЗ 28. Збереження даних юзера

У цій роботі реалізовано збереження даних користувача у `localStorage` з використанням формату JSON. Дані зберігаються при зміні полів форми та відновлюються після перезавантаження сторінки.

## Що робить програма

- Містить форму для введення даних користувача.
- Отримує значення полів форми.
- Зберігає актуальний стан полів у `localStorage`.
- Дані користувача зберігаються у вигляді одного об'єкта.
- Об'єкт серіалізується за допомогою `JSON.stringify()`.
- При завантаженні сторінки дані отримуються з `localStorage`.
- За допомогою `JSON.parse()` збережений JSON перетворюється назад в об'єкт.
- Збережені значення автоматично відновлюються у відповідних полях форми.
- При зміні текстових полів дані оновлюються в `localStorage`.
- Для `select` та `checkbox` збереження виконується при зміні значення.
- Реалізована валідація введених даних.
- Дані можна видалити за допомогою кнопки очищення.

## Формат збереження

Дані користувача зберігаються в `localStorage` під одним ключем у JSON-форматі:

```text
{
    "email": "...",
    "password": "...",
    "passwordRepeat": "...",
    "age": "...",
    "city": "...",
    "terms": true
}
```
Для перетворення об'єкта в `JSON` використовується `JSON.stringify()`, а для відновлення об'єкта з `JSON` використовується `JSON.parse()`.
