# Дз 17

В этой работе реализована функция `padString`, которая изменяет длину строки: дополняет её указанным символом или обрезает до нужной длины.

---

# Что делает программа

1. Принимает исходную строку, нужную длину, символ и направление добавления.

2. Проверяет переданные аргументы и выводит разные сообщения об ошибках при неправильных данных.

3. Если строка длиннее нужного размера, обрезает её с помощью `substring()`.

4. Если строка короче нужной длины, добавляет символы до нужного размера.

5. Может добавлять символы справа или слева.

6. Если направление не указано, символы добавляются справа.

7. Возвращает готовую строку через `return`.

8. Выводит результаты проверки функции в консоль.
