# Дз 10

В этой работе создана функция `describe()`, которая принимает любое значение и возвращает его подробное описание.

Функция определяет тип данных, значение и дополнительную информацию в зависимости от переданного значения.

---

# Что делает программа

1. Создаёт функцию `describe()` для определения типа и значения данных.

2. Отдельно обрабатывает особенности JavaScript:
   - `null`;
   - массивы;
   - `NaN`.

3. Для строк выводит их длину.

4. Для массивов выводит количество элементов и описание каждого элемента.

5. Для объектов выводит список ключей и описание значений каждого свойства.

6. Для функций выводит количество принимаемых аргументов.

7. Поддерживает типы `BigInt` и `Symbol`.

8. Использует рекурсию для обработки вложенных массивов и объектов.

9. Создаёт массив `testValues` с разными типами данных и проверяет их с помощью цикла `for`.

10. Выводит результаты работы функции в консоль браузера.
