# Дз 21

В этой работе выполнена обработка массивов объектов с помощью основных методов массивов JavaScript: `map()`, `filter()`, `reduce()`, `find()` и `some()`.

---

# Что делает программа

1. Преобразует массив продуктов в массив строк формата `Name: $price`.
2. Если товар отсутствует на складе (`inStock === false`), добавляет к строке `(out of stock)`.
3. Фильтрует пользователей по нескольким условиям:
   - пользователь активен;
   - возраст от 18 до 35 лет включительно;
   - email не заканчивается на `@spam.com`.
4. Группирует транзакции по категории и вычисляет общую сумму `amount` для каждой категории.
5. Находит первый заказ, содержащий товар с `sku === "B2"`.
6. Выводит исходные данные и результаты выполнения заданий в консоль.
