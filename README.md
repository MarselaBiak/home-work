# Дз 20

В этой работе выполнен поиск и обработка элементов массива с помощью методов массивов, математических методов и условий.

---

# Что делает программа

1. Находит сумму положительных элементов массива.

2. Подсчитывает количество положительных элементов.

3. Находит минимальный элемент массива и его порядковый номер.

4. Находит максимальный элемент массива и его порядковый номер.

5. Подсчитывает количество отрицательных элементов.

6. Подсчитывает количество положительных нечётных элементов.

7. Подсчитывает количество положительных чётных элементов.

8. Находит сумму положительных чётных элементов.

9. Находит сумму положительных нечётных элементов.

10. Находит произведение всех положительных элементов.

11. Находит максимальный элемент массива и создаёт новый массив, в котором все остальные элементы заменяются на `0`.

12. Выводит результаты выполнения каждого задания в консоль.
