# Дз 7

В этой работе выполнены эксперименты с оператором `typeof` и проверкой разных типов данных в JavaScript.

---

# Что делает программа

1. Проверяет типы 20 разных значений с помощью `typeof`.

2. Проверяет такие типы данных:
   - `number`;
   - `bigint`;
   - `string`;
   - `boolean`;
   - `undefined`;
   - `symbol`;
   - `object`;
   - `function`.

3. Проверяет специальные значения:
   - `null`;
   - `NaN`;
   - `Infinity`;
   - необъявленную переменную.

4. Проверяет тип:
   - обычного объекта;
   - пустого массива;
   - массива с числами;
   - обычной функции;
   - стрелочной функции.

5. Проверяет результат разных выражений:
   - сложение двух чисел;
   - сложение строки и числа;
   - вычитание двух строк;
   - двойное использование `typeof`.

6. Создаёт таблицу в файле `answers.md`, где указаны:
   - выражение;
   - моя гипотеза;
   - реальный результат;
   - объяснение результата.

7. Создаёт раздел «Підозрілі справи» и объясняет особенности:
   - `typeof null`;
   - `typeof []`;
   - `typeof NaN`;
   - `typeof nonExistentVariable`.

8. Показывает правильные способы проверки:
   - `null` через строгое сравнение;
   - массива через `Array.isArray()`;
   - `NaN` через `Number.isNaN()`.

9. Создаёт функцию `isReallyArray()`, которая проверяет, является ли значение массивом.

10. Проверяет функцию `isReallyArray()` на:
   - массиве;
   - строке;
   - объекте со свойством `length`;
   - значении `null`;
   - результате метода `.split()`.

11. Создаёт функцию `whatIsIt()`, которая возвращает точный тип значения.

12. Функция `whatIsIt()` отдельно определяет:
   - `null`;
   - массив;
   - объект;
   - функцию;
   - строку;
   - число;
   - `undefined`.

13. Выводит результаты всех проверок в консоль.
