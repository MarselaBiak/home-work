# ДЗ 27

У цій роботі реалізовано форму реєстрації користувача з live- та submit-валідацією, збереженням даних у localStorage та серіалізацією даних у формат JSON.

## Що робить програма

- Містить поля для введення email, пароля, підтвердження пароля та віку.
- Дозволяє вибрати місто та підтвердити згоду з умовами.
- Виконує live-валідацію полів під час їх заповнення.
- Перевіряє правильність введеного email.
- Перевіряє пароль на мінімальну довжину, наявність цифри та літери.
- Перевіряє відповідність підтвердження пароля основному паролю.
- Перевіряє вік у діапазоні від 16 до 120 років.
- Перевіряє вибір міста та згоду з умовами.
- Під час відправлення форми виконується повторна перевірка всіх полів.
- Якщо дані некоректні, форма не відправляється, а фокус переходить на перше невалідне поле.
- Після успішної перевірки дані збираються в об'єкт.
- Дані серіалізуються за допомогою JSON.stringify() та відображаються під формою.
- Дані форми зберігаються у localStorage.
- Після перезавантаження сторінки збережені дані відновлюються.
- Кнопка "Очистити" очищає форму, localStorage, повідомлення про помилки та JSON-результат.
- Реалізована можливість показувати та приховувати пароль.
