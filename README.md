# Дз 8

В этой работе изучены значения `undefined` и `null`, причины их появления и способы безопасной работы с ними в JavaScript.

---

# Что делает программа

1. Проверяет разные случаи появления `undefined` и `null`.

2. Создаёт таблицу в файле `answers.md`, где указаны:
   - сцена;
   - результат выполнения;
   - причина появления значения;
   - способ избежать проблемы.

3. Проверяет переменную, которой не присвоили значение.

4. Проверяет переменную со значением `null`.

5. Проверяет вызов функции без аргумента.

6. Проверяет функции:
   - с правильным `return`;
   - без `return`;
   - с пустым `return`.

7. Проверяет обращение:
   - к отсутствующему свойству объекта;
   - к несуществующему элементу массива;
   - к отсутствующему вложенному свойству.

8. Создаёт функцию `describeEmpty()`, которая определяет:
   - значение `undefined`;
   - значение `null`;
   - остальные значения.

9. Функция `describeEmpty()` выводит:
   - кто создал пустое значение;
   - тип обычного значения;
   - само значение.

10. Проверяет функцию `describeEmpty()` на:
    - `null`;
    - `undefined`;
    - числе `0`;
    - пустой строке;
    - пустом массиве;
    - значении `false`.

11. Исправляет код, который создавал `undefined`:
    - присваивает значения переменным;
    - возвращает результат функции через `return`.

12. Использует оператор optional chaining `?.`.

13. Безопасно получает вложенное свойство `email`.

14. Для объекта без свойства `contact` возвращает `undefined` без ошибки.

15. Выводит результаты всех проверок в консоль.
