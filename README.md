# Дз 9

В этой работе изучен тип данных `Symbol` в JavaScript.

`Symbol` используется для создания уникальных значений. Даже если несколько символов имеют одинаковое описание, они всё равно являются разными.

---

# Что делает программа

1. Создаёт трёх участников клуба.

2. Каждый участник содержит:
   - уникальный `id`;
   - имя;
   - дату вступления в клуб.

3. Для создания уникального `id` используется:

   ```js
   Symbol('member')
   ```
4. Выводит созданных участников клуба в консоль.

5. Создаёт два похожих объекта и сравнивает:
   - сами объекты;
   - их `Symbol`;
   - имена;
   - описания символов.

6. Показывает, что каждый вызов `Symbol()` создаёт новое уникальное значение, даже если описание одинаковое.

7. Проверяет сравнение символов через `===` и `==`.

8. Преобразует `Symbol` в строку с помощью:
   - `String()`;
   - `.toString()`;
   - `.description`.

9. Использует `Symbol` как уникальный ключ объекта.

10. Проверяет доступ к символьному свойству и работу метода `Object.keys()`.

11. Создаёт массив участников клуба и функцию `findMember()` для поиска участника по его уникальному `id`.

12. Проверяет поиск участника по существующему и новому `Symbol`.

13. Сравнивает работу `Symbol()` и `Symbol.for()`.

14. Выводит результаты всех проверок в консоль.
