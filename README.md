# Дз 23

В этой работе выполнена работа с DOM-деревом страницы, вложенными списками `ul/li` и получением данных из HTML-элементов с помощью JavaScript.

---

# Что делает программа

1. Создаёт дерево, структурированное с помощью вложенных списков `ul` и `li`.

2. Находит все элементы `li` на странице с помощью `querySelectorAll()`.

3. Перебирает найденные элементы с помощью цикла `for...of`.

4. Выводит каждый элемент списка в консоль.

5. Определяет общее количество элементов `li` с помощью свойства `length`.

6. Получает текстовое содержимое каждого элемента `li` через свойство `textContent`.

7. Создаёт массив для хранения текста элементов списка.

8. Добавляет текст каждого элемента `li` в массив с помощью метода `push()`.

9. Выводит полученный массив в консоль.
