# Дз 15

В этой работе выполнены задания на работу с `parseInt`, `Number`, остатком от деления `%`, циклами и проверкой пользовательского ввода.

---

# Что делает программа

1. Проверяет разные варианты работы `parseInt()` и `Number()`.

2. Реализует игру «Угадай число» с проверкой неправильного ввода и ограничением в 5 попыток.

3. Переводит количество секунд в формат `часы:минуты:секунды`.

4. Считает сумму цифр числа и его цифровой корень.

5. Разменивает сумму денег минимальным количеством купюр и монет.
