# **Дз 25**

В этой работе реализовано раскрытие и скрытие дополнительного текста в карточках с помощью `data-*` атрибутов, метода `closest()`, делегирования событий и `classList`.

---

# **Что делает программа**

1. На странице размещено несколько карточек с коротким и длинным текстом.

2. Длинный текст каждой карточки изначально скрыт.

3. Для кнопок используется атрибут `data-read-more-btn`.

4. JavaScript находит общий контейнер карточек с помощью `querySelector()`.

5. Для контейнера устанавливается единый обработчик события `click`.

6. При клике с помощью `closest()` определяется кнопка, по которой был выполнен клик.

7. С помощью `closest()` также определяется карточка, к которой относится нажатая кнопка.

8. При нажатии на кнопку карточке добавляется или удаляется класс `expanded`.

9. Класс `expanded` используется для отображения или скрытия длинного текста.

10. Текст кнопки изменяется в зависимости от состояния карточки:
    - `Read more` — если текст скрыт;
    - `Hide` — если текст отображается.

11. Для проверки состояния карточки используется `classList.contains()`.

12. Для изменения класса используется `classList.toggle()`.

13. Для изменения текста кнопки используется свойство `textContent`.

14. Один обработчик событий работает сразу для всех карточек благодаря делегированию событий.

15. Решение работает с любым количеством карточек в контейнере.
